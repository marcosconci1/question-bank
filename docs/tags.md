# Tag Taxonomy (concept registry)

The other half of the QUESTION—CONCEPT relationship. Questions carry tag
slugs; this file is the registry that gives each slug a name, a level, and
(in the future) cross-source aliases.

Format: one concept per line, `slug | display name | level`.
Levels: `area` (knowledge area) > `topic` > `subtopic`. Aliases map slugs
from other sources onto the canonical one.

## Registry (seeded from POSCOMP's own hierarchy)

carried over from the official exam taxonomy, and questions themselves are
in Portuguese); slugs and everything system-side are English.

## Rules

1. A tag used by any question file MUST be registered here (validator
   enforces once ENADE import lands).
2. Merging sources = adding aliases here, never editing question files.
3. Hierarchy is expressed by level + convention (subtopics are prefixed by
   their topic in the question's tag list), not by nesting in this file.
